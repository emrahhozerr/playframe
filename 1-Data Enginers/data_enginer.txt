Data Enginers/
-----------------
1-players.py         = players.csv'yi temizler (rol/ulke bilgisini sozlukten cikarir, boy-kilo eksiklerini pozisyona gore doldurur) -> playerss.csv
2-temas.py           = teams.csv'yi temizler (ulke bilgisini sozlukten cikarir) -> teamss.csv
3-tags2name.py       = tag ID -> tag ismi referans tablosunu oldugu gibi kopyalar -> tags_2_namee.csv
4-players_games.py   = player_games.csv'yi temizler (0 dakika oynayanlari siler, sutunlari duzenler) -> players_gamee.csv
5- matches_england.py= mac formasyon JSON'unu acar, kadro/kart/degisiklik bilgisi cikarir, hatali kendi kalesine gol sutunlarini atar -> matches_engg.csv
6-Events_England.py  = event konumlarini (x/y) regex ile yeniden uretir, tag'leri one-hot encode eder -> event_englandd.csv
7-eventid2name.py    = event/subevent ID -> isim referans tablosu -> event_id_2_namee.csv
all.py               = yukaridaki 5 temiz tabloyu birlestirip 3 final tablo uretir (oyuncu-mac, event, tag) -> player_game_merged.csv, event_england_merged.csv, event_tags_long.csv
pipline.py           = Ingiltere icin yukaridaki 8 fonksiyonu dogru sirada calistiran ana orkestrator
prime_key.txt         = tablolarin birbirine hangi ID uzerinden baglandigini gosteren diyagram (dokumantasyon, kod degil)
